LifeOS 人生第二大脑 · 隐私政策

最后更新日期：2026-11-05　生效日期：2026-11-05

欢迎使用 LifeOS 人生第二大脑（以下简称"本应用"）。本应用是一款帮助用户管理任务、目标、日程、笔记、学习与健康的个人效率工具。我们非常重视您的个人信息和隐私保护。请您在使用本应用前，仔细阅读并理解本隐私政策。一旦您开始使用本应用，即表示您已同意本政策所述内容。

一、我们如何收集和使用您的信息

本应用仅在为您提供服务所必需的范围内收集信息，且绝大多数数据仅存储于您的本地设备，不会主动上传至我们的服务器。我们收集的信息包括：

  • 账号信息：您注册时提供的手机号或邮箱、登录密码（以加密形式保存在本地）。用于账号登录与多设备隔离。
  • 您主动录入的内容：任务、目标、日程、笔记、学习资料、财务记录、物品清单、健康记录（步数等）、单词卡等。这些数据是应用的核心功能载体，仅保存在本地设备。
  • 设备信息：设备型号、系统版本等，用于界面适配与兼容性处理。
  • 运动健康数据：在您授权后，通过系统"运动健康"能力（ohos.permission.ACTIVITY_MOTION，简称 ACTIVITY_MOTION）读取步数，用于健康看板展示。我们仅在本机读取与展示，不上传。
  • 麦克风与语音数据：在您主动使用语音速记或语音输入时，经您明确授权后，调用系统麦克风能力（ohos.permission.MICROPHONE，简称 MICROPHONE）采集音频并实时转换为文字写入笔记或任务。音频仅用于即时本地转写，不作商业留存，不上传至第三方服务器。
  • AI 对话内容：当您使用"AI 助手"功能并主动配置云端模型后，您输入的问题会发送给您所配置的第三方大模型服务进行处理（见下文"第三方服务"）。未配置时，对话由应用内本地规则引擎处理，不上传任何内容。对话历史保存在本地。

二、第三方服务

为提供 AI 对话能力，仅在您主动配置 API Key 后，本应用才会调用以下第三方服务。相关数据的处理受对应服务商的隐私政策约束：

  • 硅基流动（SiliconFlow）/ DeepSeek：当您配置其 API Key 后，AI 对话内容会通过其 OpenAI 兼容接口处理。

除上述情形外，我们不会将您的个人信息提供给任何第三方。

三、信息的存储与安全

  • 您的业务数据主要保存在本地设备（应用沙箱）中，采用按账号隔离的持久化存储。
  • 我们采取合理的加密与访问控制措施保护您的本地数据，包括可选的"启动验证"与"数据脱敏"开关。
  • 如您卸载应用且未主动导出数据，本地数据将随应用一并清除。

四、您的权利

您对自己的个人信息享有充分的控制权，可通过应用内功能：

  • 查询、更正或删除任意一笔录入数据（任务 / 笔记 / 财务等）；
  • 在"设置 → 数据概览 / 导出"中导出全部数据为本地文件；
  • 在"设置 → 隐私与安全"中开启启动验证与数据脱敏；
  • 注销账号并清除本地全部数据。

五、儿童隐私

本应用主要面向成年用户，不面向 14 周岁以下儿童。我们不会有意收集儿童的个人信息。如您发现我们不慎收集了儿童信息，请与我们联系，我们将立即删除。

六、政策的更新

我们可能根据法律法规或产品变化更新本政策。更新后的政策将在应用内或本页面公示，并在生效前以合理方式通知您。

八、应用权限声明（敏感权限清单）

本应用为向您提供服务，会在您使用相关功能时申请以下系统权限。我们严格遵循"最小必要"原则，仅在功能所必需的范围内使用这些权限：

权限名称 权限类型 申请目的与用途 使用场景
ohos.permission.INTERNET 普通权限（安装即授权） 用于 AI 对话、云端同步等需要联网的功能。 应用内联网功能，按需使用，不上传无关个人信息。
ohos.permission.ACTIVITY_MOTION 敏感权限（user_grant，需您授权） 读取设备步数等运动健康数据，用于健康看板展示。 您在"健康"模块查看步数时，经您授权后在本机读取与展示，不上传。
ohos.permission.MICROPHONE 敏感权限（user_grant，需您授权） 采集麦克风音频，用于语音速记 / 语音输入实时转写为文字。 您主动点击"语音输入"并授权后录制，音频仅用于即时本地转写，不作留存、不上传。

上述敏感权限（ohos.permission.ACTIVITY_MOTION、ohos.permission.MICROPHONE）均会在您首次使用相关功能时弹窗征得您的明确同意；您可随时在系统的"设置 → 应用管理 → LifeOS → 权限"中撤回授权，撤回后相关功能将不可用，但不影响其他功能的使用。
